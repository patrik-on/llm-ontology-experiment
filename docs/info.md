# Documentation map

- `architecture/`: project map, system boundaries, repository policy, current
  reorganization audit, cleanup candidates, and preserved historical audits;
- `datasets/`: dataset contracts and handcrafted smoke documentation;
- `finetuning/`: active LoRA/QLoRA design, WSL setup, runbooks, and adapter handoff;
- `retrieval/`: RAG phases, MultiRAG/RRF baseline, and Ollama embedding lifecycle;
- `evaluation/`: evaluation runbooks;
- `experiments/`: experiment design, split/environment contract, and TestBench runbook;
- `thesis/`: reproducible research handoff material;
- `ui/`: interactive UI and environment-status documentation.

Start with `architecture/project_map.md`. Root `README.md` is the public quick
entry; `devinfo.md` contains non-negotiable methodological and ownership rules.
